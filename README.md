# Apollo

Generative call-and-response for Ableton Operator (FM synth). Given a short MIDI phrase, produce a complementary MIDI response in the user's authored style.

Training corpus is hand-authored: paired MIDI tracks (call + response), both routed through an Operator instance in Ableton.

This is v2.0. The prior piano/MAESTRO codebase lives on the `deprecated` branch as historical reference only.
