- `start(self, pairs_root, epochs, output_dir)`: under lock, return False if status=="running"; else set status="running", reset epoch/loss_history; build `cmd = ["python","-m","apollo.scripts.train", pairs_root, "--epochs", str(epochs), "--output-dir", output_dir]`; `subprocess.Popen(cmd, stdout=subprocess.PIPE, stderr=subprocess.STDOUT, text=True, bufsize=1)`; spawn daemon `threading.Thread(target=self._read_stdout)`; return True.
- `_read_stdout(self)`: compile `re.compile(r"epoch (\d+)/(\d+)\s+train_loss=([\d.]+)\s+held_loss=([\d.nan]+)")` (this regex matches train.py's VERIFIED stdout `epoch {E}/{N}  train_loss={X:.4f}  held_loss={Y:.4f}`). Iterate `for line in self._proc.stdout:`; on match, under lock set epoch/total_epochs/train_loss, parse held_loss with try/except ValueError→None, append to loss_history. After loop: `ret = self._proc.wait()`; under lock `self.status = "complete" if ret == 0 else "error"`. DO NOT use `communicate()`.
- `snapshot(self) -> dict`: under lock return dict of status, epoch, total_epochs, train_loss, held_loss, loss_history (copy the list).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → Flask routes | `<nnn>` and `<filename>` path segments are untrusted user input crossing into filesystem path construction |
| Flask → filesystem | send_file / load_notes read files under PAIRS_ROOT |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering/Info-disclosure | `/midi/<nnn>` and `/audio/<nnn>` routes (path traversal) | mitigate | `_validate_pair_nnn` rejects any nnn not in the filesystem-enumerated `_known_pairs_set()` with abort(404) BEFORE the nnn is used to build a path; `filename` is allow-listed (`call.mid`/`response.mid` for /midi, `call.wav` for /audio). Test asserts `/midi/../etc/...` → 404. |
| T-05-02 | Information disclosure | Server binding | mitigate | Bind `127.0.0.1` only (never 0.0.0.0); `debug=False`. Asserted by grep in acceptance criteria. |
| T-05-03 | Denial of service | load_notes on `/midi` | accept | load_notes already enforces MAX_NOTES_PER_PAIR=1000 cap (shipped Phase 1); local single-user app, low risk. |
</threat_model>
