CANONICAL DSP topology to mirror (apollo/synth/spec.py _body_no_lfo; DSP ops are 1-based, JS operators[] is 0-based):
  STACK(0):         mod3=op3*op3_level*freq; mod2=osc(freq*op2_ratio+mod3)*op2_env*op2_level*freq; car=osc(freq*op1_ratio+mod2)*op1_env*op1_level
  PARALLEL_MODS(1): mod2=op2*op2_level*freq; mod3=op3*op3_level*freq; car=osc(freq*op1_ratio+mod2+mod3)*op1_env*op1_level
  CARRIER_PAIR(2):  mod3=op3*op3_level*freq; car1=osc(freq*op1_ratio+mod3)*op1_env*op1_level; car2=op2*op2_level (independent additive carrier)
  all bodies end: process = (...) * gain;
  KEY: modulator amplitude scales as op_level*freq (DX-style index∝pitch). In Web Audio: GainNode(gain=op.level*freq) connected to the target oscillator's .frequency AudioParam.

LFO formulas (data/pairs/CORPUS-CONVENTIONS.md; one global LFO applied to ALL carriers uniformly; CARRIER_PAIR both carriers move together):
  lfo_bi = raw osc in [-1,1]; lfo_uni = (lfo_bi+1)/2
  TREMOLO (target 0): lvl_mod = 1 - depth*(1 - lfo_uni)  → constant (1-depth/2) + lfo_bi*(depth/2); carrier gain swings in [1-depth,1]
  VIBRATO (target 1): pitch_mul = pow(2, lfo_bi*depth*50/1200); 50 cents max at depth=1
    audition linear approx (D-15 allows): freq offset ≈ freq*depth*50/1200*Math.LN2*lfo_bi added to each carrier osc .frequency
  LFO phase resets per note: create a NEW OscillatorNode per note-on started at scheduled `when`.

Hand-roll a Web Audio FM engine (NO Tone.js — it is 2-op only). Attach a global `ApolloSynth` to `window` with these functions:

`midiToHz(pitch)` → `440 * Math.pow(2, (pitch - 69) / 12)`.

`applyAdsr(gainParam, op, when, noteDuration)` — verbatim RESEARCH Pattern 4:
```
gainParam.cancelScheduledValues(when);
gainParam.setValueAtTime(0, when);
gainParam.linearRampToValueAtTime(1.0, when + op.attack);
gainParam.linearRampToValueAtTime(op.sustain, when + op.attack + op.decay);
gainParam.setValueAtTime(op.sustain, when + noteDuration);
gainParam.linearRampToValueAtTime(0, when + noteDuration + op.release);
```

`playNote(audioCtx, patch, pitch, velocity, when, duration, master)`:
- `const freq = midiToHz(pitch);`
- Build 3 operators: for each `op` of `patch.operators` create `osc=audioCtx.createOscillator()` (`osc.type='sine'`, `osc.frequency.value=freq*op.ratio`) + `env=audioCtx.createGain()`; `applyAdsr(env.gain, op, when, duration)`; `osc.connect(env)`; `osc.start(when)`; `osc.stop(when+duration+op.release+0.05)`. Keep `{osc, env, level:op.level}`.
- `const noteGain=audioCtx.createGain(); noteGain.gain.value=patch.gain*(velocity/127); noteGain.connect(master||audioCtx.destination);`
- `wireMod(srcEnv, dstParam, level)`: `const g=audioCtx.createGain(); g.gain.value=level*freq; srcEnv.connect(g); g.connect(dstParam);`  // op_level*freq DX index scaling onto .frequency
- `wireCarrier(env, level)`: `const cg=audioCtx.createGain(); cg.gain.value=level; env.connect(cg); cg.connect(noteGain); return cg;`  // returns carrier output node so LFO can target it
- Branch on `patch.algorithm` (use ALGORITHMS); collect `carriers` as `[{gainNode, osc, level}, ...]`:
  - STACK(0): `wireMod(ops[2].env, ops[1].osc.frequency, ops[2].level); wireMod(ops[1].env, ops[0].osc.frequency, ops[1].level); carriers=[{gainNode:wireCarrier(ops[0].env,ops[0].level), osc:ops[0].osc, level:ops[0].level}]`.
  - PARALLEL_MODS(1): `wireMod(ops[1].env, ops[0].osc.frequency, ops[1].level); wireMod(ops[2].env, ops[0].osc.frequency, ops[2].level); carriers=[{gainNode:wireCarrier(ops[0].env,ops[0].level), osc:ops[0].osc, level:ops[0].level}]`.
  - CARRIER_PAIR(2): `wireMod(ops[2].env, ops[0].osc.frequency, ops[2].level); carriers=[{gainNode:wireCarrier(ops[0].env,ops[0].level),osc:ops[0].osc,level:ops[0].level},{gainNode:wireCarrier(ops[1].env,ops[1].level),osc:ops[1].osc,level:ops[1].level}]`  // op2 is an independent additive carrier (its osc already runs at freq*op2_ratio, no modulator)
- `attachLfo(audioCtx, patch, carriers, freq, when, duration);`

`attachLfo(audioCtx, patch, carriers, freq, when, duration)`:
- `if (!patch.lfo) return;`  // no LFO ⇒ no modulation (matches v1.0 path)
- `const {rate, depth, wave, target} = patch.lfo;`
- `const lfoOsc=audioCtx.createOscillator(); lfoOsc.frequency.value=rate; lfoOsc.type=['sine','triangle','square'][wave]; lfoOsc.start(when); lfoOsc.stop(when+duration+0.2);`  // NEW osc per note = phase reset (mirrors os.osc per-voice reset)
- if `target === LFO_TARGETS.LEVEL` (0) — TREMOLO. For each carrier, drive its gain with constant `level*(1-depth/2)` plus lfo `level*(depth/2)`:
  ```
  carriers.forEach(c => {
    c.gainNode.gain.value = 0;
    const dc = audioCtx.createConstantSource(); dc.offset.value = c.level*(1 - depth/2); dc.connect(c.gainNode.gain); dc.start(when);
    const lg = audioCtx.createGain(); lg.gain.value = c.level*(depth/2); lfoOsc.connect(lg); lg.connect(c.gainNode.gain);
  });
  ```
- else (target PITCH=1) — VIBRATO linear audition approx:
  ```
  const maxDev = freq * depth * 50 / 1200 * Math.LN2;
  const lg = audioCtx.createGain(); lg.gain.value = maxDev; lfoOsc.connect(lg);
  carriers.forEach(c => lg.connect(c.osc.frequency));
  ```

`playSequence(audioCtx, patch, notes)`: `const t0=audioCtx.currentTime+0.05; const master=audioCtx.createGain(); master.gain.value=1; master.connect(audioCtx.destination); notes.forEach(n => playNote(audioCtx, patch, n.pitch, n.velocity, t0+n.start, n.duration, master));`
