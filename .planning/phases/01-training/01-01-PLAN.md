<objective>
Fix a checkpoint collision bug in modal_train.py, then launch v3 and v4 training runs in parallel.

Purpose: Both configs write checkpoints to the same `/checkpoints/` volume path, so running them in parallel would cause v3 and v4 to overwrite each other's `checkpoint_best.pt`. A one-line fix routes each run to its own subdirectory. After the fix, launch both runs simultaneously per D-01.

Output: Two active Modal A100 training jobs; v3 checkpoints at `/checkpoints/apollo_v3_mel/`, v4 at `/checkpoints/apollo_v4_streaming/`.
</objective>
