    `def render(params: FmParams, notes, *, pair_path: str) -> np.ndarray`:
    1. Derive duration deterministically: `max_release = max(op.release for op in params.operators)`; `dur = max(n.end for n in notes) + max_release + 0.1` (RESEARCH §"Render duration" — cover the longest release tail; MelExtractor pads short, so erring long is safe, under-rendering clips the tail).
    2. Cap: `if dur > MAX_RENDER_SECONDS: raise IngestError(pair_path, f"render duration {dur:.2f}s exceeds cap ({MAX_RENDER_SECONDS}s)")` (T-06 DoS).
    3. Build engine: `engine = dd.RenderEngine(SR, BLOCK)`; `synth = engine.make_faust_processor("fm")`; `synth.set_dsp_string(dsp_string(params))`; `synth.num_voices = NUM_VOICES`.
    4. LANDMINE — resolve param indices at runtime: call `synth.get_parameters_description()` once, build a `name -> index` dict, then `synth.set_parameter(<int index>, value)` for each per-op `ratio`/`level`/`attack`/`decay`/`sustain`/`release` using the slider names spec.dsp_string emits (per 06-01-SUMMARY). NEVER set by path string; NEVER hardcode indices. `freq`/`gain`/`gate` are MIDI-owned — do not attempt to set them.
    5. Add notes: `for n in notes: synth.add_midi_note(n.pitch, n.velocity, n.start, n.end - n.start)` (pass velocity straight through — DawDreamer maps velocity->gain internally; do NOT double-apply manifest gain to velocity).
    6. `engine.load_graph([(synth, [])])`; `engine.render(dur)`; `audio = engine.get_audio()`.
    7. Mono: if audio has >1 channel, take channel 0 or mean to 1-D (mono recommended — removes L/R asymmetry as a determinism variable).
    8. Normalize (scalar peak, deterministic): `peak = float(np.max(np.abs(audio)))`; `audio = audio / max(peak, 1e-9) * TARGET_PEAK`. Do NOT use RMS/loudness/compressor (non-linear stages distort the timbre conditioning signal — RESEARCH §"Normalization").
    9. Return `audio` as float32 1-D (shape soundfile.write accepts).

    LANDMINE — filter the benign `undefined symbol : effect` warning emitted by the poly factory (suppress/redirect it from stderr/logs so it doesn't pollute CLI output). Do NOT reference `dawdreamer.__version__`.

    `def render_call_wav(manifest_path: str, mid_path: str, *, pair_path: str, call_bpm: float = 120.0, notes=None) -> np.ndarray`: the SINGLE shared parity entrypoint. Loads params via `load_manifest(manifest_path, pair_path)`; if `notes is None`, parse via `load_notes(mid_path, pair_path, tempo_bpm=call_bpm)` (accept a pre-parsed `notes` arg so generate.py can pass the SAME parsed call_notes and avoid double-parsing with a different tempo — RESEARCH §"Train/Serve Parity Wiring" pitfall). Returns the normalized np.ndarray from `render(...)`. Both render_corpus.py and generate.py MUST call this one function so corpus and inference renders are bit-identical.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| call_fm.json + call.mid -> render.py | Untrusted hand-authored manifest + MIDI cross into the render engine |
| render params -> DawDreamer/Faust engine | Numeric params drive a native synthesis engine (CPU/RAM cost) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-06 | DoS | apollo/synth/render.py | mitigate | Derived render `dur` capped at `MAX_RENDER_SECONDS = 30.0` (mirrors MelExtractor.MAX_WAV_SECONDS); exceeding raises IngestError before the engine runs. |
| T-06-07 | DoS | apollo/ingest/midi.py::load_notes (reused) | mitigate | MIDI note-count DoS cap (`MAX_NOTES_PER_PAIR=1000`) already enforced by the reused load_notes — not re-implemented. |
| T-06-08 | Tampering | apollo/synth/render.py param set | mitigate | Params set by runtime-resolved integer index from `get_parameters_description()`; no path string / hardcoded index that could silently target the wrong param. |
| T-06-09 | Tampering | apollo/synth/render.py velocity | mitigate | Note velocity passed straight to DawDreamer MIDI layer; manifest `gain` is a separate patch-level trim — not double-applied to velocity. |
| T-06-10 | Information Disclosure | benign Faust warning | accept | `undefined symbol : effect` is a known-benign poly-factory warning; filtered from logs. Rationale: no security impact, cosmetic only. |
