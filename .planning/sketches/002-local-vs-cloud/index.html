Why fully local
The model is ~1.1M parameters — tiny by modern standards. Apple Silicon MPS handles training and inference without any cloud dependency. Corpus is small (30–200 pairs). No scale pressure requiring remote compute.
Latency advantage
Local inference eliminates network round-trips entirely. <100ms on CPU, <10ms on MPS — fast enough for near-real-time M4L response even on a background thread. A cloud API would add 200–500ms of unavoidable network latency.
Privacy + offline
Your corpus is your musical fingerprint — it should never leave your machine. Local-only means the model trains on your style, runs on your machine, and works completely offline. No API keys, no accounts, no upload.
When would cloud become relevant? Only if the model architecture grew to the scale where MPS can't keep up — billions of parameters, or a dataset requiring multi-GPU training. Neither is planned for Apollo. The hierarchical call-and-response vision (SEED-002: gesture → theme → passage) adds model levels but each level stays small. Cloud training would be a deliberate architectural decision, not a default.
