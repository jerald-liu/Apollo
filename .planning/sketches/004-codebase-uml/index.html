sequenceDiagram
    autonumber
    participant U as User (Ableton)
    participant I as ingest_corpus.py
    participant T as train.py
    participant DS as ApolloDataset
    participant M as ApolloModel
    participant CK as checkpoint.pt

    U->>I: data/pairs/NNN/ (call.mid + call.wav + response.mid)
    I->>I: discover_pairs() → list of PairPath
    I->>I: load_notes(call.mid) → List[Note]
    I->>I: Tokenizer.encode(notes) → List[int]
    I->>I: MelExtractor(call.wav) → Tensor(96,128)
    I->>I: is_heldout(NNN) → 80/20 hash split
    I-->>T: artifact.pt (tokens + mel + metadata)

    T->>DS: ApolloDataset(artifact, split="train")
    DS-->>T: DataLoader with collate_fn

    loop each epoch (1..300)
        T->>DS: next batch
        DS-->>T: token_ids(B,64) + pad_mask(B,64) + mel(B,1,96,128)
        T->>M: forward(token_ids, mel, pad_mask)
        Note over M: mel_enc(mel) → (B,128) prefix
cat [prefix, tok_emb + pos_emb]
causal transformer (4 layers)
drop prefix, project → (B,T,256) logits
        M-->>T: logits (B,T,256)
        T->>T: masked CE loss (response tokens only, after SEP)
        T->>T: backprop + OneCycleLR step
        T->>T: eval held-out loss every N epochs
    end

    T->>CK: save_checkpoint (model, optimizer, metrics, epoch)
    Note over CK: apollo_iter{N}_best.pt (3.7 MB)

sequenceDiagram
    autonumber
    participant U as User
    participant G as generate.py
    participant TOK as Tokenizer
    participant MEL as MelExtractor
    participant M as ApolloModel
    participant AB as Ableton

    U->>G: checkpoint.pt + call.mid + call.wav
--n 4 --temperature 0.8 --top-k 10
    G->>G: load_checkpoint(checkpoint.pt)
    G->>TOK: encode(load_notes(call.mid))
    TOK-->>G: call_tokens: List[int]
    G->>MEL: MelExtractor(call.wav)
    MEL-->>G: mel: Tensor(1,1,96,128)

    loop n=4 samples
        G->>G: prompt = [BOS] + call_tokens + [SEP]
        loop autoregressive (up to max_tokens)
            G->>M: forward(prompt, mel)
            M-->>G: logits for next token
            G->>G: apply temperature (0.8)
            G->>G: top-k filter (k=10)
            G->>G: sample from distribution
            alt EOS sampled
                G->>G: stop generation
            else token sampled
                G->>G: append to prompt
            end
        end
        G->>TOK: decode(response_tokens)
        TOK-->>G: List[Note]
        G->>G: write response_NNN.mid
    end

    G-->>U: response_001.mid .. response_004.mid
    U->>AB: drag into Ableton, play through any preset

Diagram notes:
• Vocab.VOCAB_SIZE=256 — 112 active IDs (pitch/vel/time/dur + BOS/EOS/SEP), 144 reserved for future pitch-bend/CC tokens
• MEL prefix is injected at position 0 of the transformer sequence; output at position 0 is dropped before the vocabulary projection
• Pad mask is length-based (never token_ids == 0) because PAD_ID=0 overlaps with TIME_SHIFT bin 0
• Loss is masked to response tokens only (positions after SEP) — the model learns to generate, not autoencode
• Total params: ~1.1M (976K transformer + 109K MelEncoder). Checkpoint: ~3.7 MB
• Everything runs on Apple Silicon MPS. No cloud dependencies.
