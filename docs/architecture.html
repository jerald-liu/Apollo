Apollo — System Architecture

Proposed dual-channel I/O · multi-modal · multi-scale · Phase roadmap

01 · Proposed System Architecture

Audio is the perceptual ground truth — always present. MIDI enriches when available; a soft pitch head generates a continuous symbolic representation on-the-fly when it isn't. Two output channels: a waveform via neural codec decoder, and MIDI CC values for synth control.

02 · Training Workload Flow

MAESTRO audio + MIDI preprocessed locally, pushed to Modal persistent volume. A100 training run consumes memory-mapped .npy arrays, checkpoints back to volume.

03 · Real-Time Inference Flow

Target latency budget: <20 ms end-to-end from input event to first output token. Audio analysis in Max/MSP, inference in Python, dual output back to M4L.
