# Apollo — v2.0 "Call-and-Response v1"

## What This Is

A generative model that, given a short MIDI phrase played through an Ableton **Operator** (FM synth) instance, produces a complementary MIDI response of similar length. Training corpus is **hand-authored by the user** — two MIDI tracks per pair, both running Operator: track 1 is the call, track 2 is the response.

This branch (`call-and-response-v1`) is a clean start. No code is carried forward — the prior piano/MAESTRO codebase lives only on the `deprecated` branch for reference and is not a model lineage.

## Current State

Nothing built yet. See the corpus-direction memory for the full plan, roadmap, and open questions.
